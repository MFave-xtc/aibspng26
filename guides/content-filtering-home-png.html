How to Set Up Content Filtering at Home

Audience: Parents, home users
Difficulty: Intermediate
Time: 30 minutes
Last reviewed: June 2026

1 Quick Summary

Content filtering blocks access to unsafe websites on your home internet. This guide covers two practical methods for PNG homes: changing your router's DNS settings to a family-safe filter, and using browser-level controls such as Google SafeSearch and YouTube Restricted Mode.

These two methods work together. Router DNS filtering covers all devices on your Wi-Fi network. Browser controls add a second layer of protection for specific services like Google Search and YouTube.

What you will achieve: After completing this guide, all devices connected to your home Wi-Fi will have DNS-based content filtering applied, and your browsers will be configured with SafeSearch and Restricted Mode enabled.

2 PNG Reality Check

PNG Reality Check

In PNG homes, a single router often connects multiple phones, tablets, and computers. Changing the DNS settings on the router applies filtering to all devices on that network — including older devices that cannot run parental control apps.

Mobile data connections bypass home router filtering entirely. If a child or family member uses mobile data on their phone rather than the home Wi-Fi, the router DNS settings will not apply to them. Additional device-level settings are needed for phones that use mobile data outside the home.

Many PNG homes have inconsistent power supply. A power outage will not permanently affect your DNS settings — they will be retained when the router restarts. However, if you are mid-setup when power cuts, you will need to log back in and confirm whether your changes were saved.

3 What Content Filtering Can and Cannot Do

Content filtering is not a complete solution. Children should also be taught about online safety, and family conversations about internet use are important. Determined teenagers can bypass DNS-based filtering by using a VPN, switching to mobile data, or using a proxy service. DNS filtering works best as one layer of protection alongside open conversations and supervision — not as a replacement for them.

DNS filtering is effective for:

  • Blocking accidental access to adult content for younger children
  • Blocking known malware and phishing sites for all family members
  • Covering all devices on the network without software on each device

DNS filtering does not protect against:

  • Devices using mobile data instead of home Wi-Fi
  • VPN usage that routes traffic around your DNS settings
  • Content within apps that do not use your browser (messaging apps, games)
  • Harmful content shared directly by friends or contacts in messages

4 Method 1 — DNS Filtering on Your Router

DNS filtering works by pointing your router to a family-safe DNS server that refuses to resolve the addresses of blocked websites. When any device on your Wi-Fi tries to visit a blocked site, the DNS server returns nothing, and the browser shows a "site not found" message.

This method requires you to access your router's admin panel. If you have not done this before, read the Secure Your Wi-Fi Router guide first — it covers how to find your router's admin address and log in.

Step 1

Access Your Router Admin Panel

You need to be connected to your home Wi-Fi to do this. Open a browser on your phone or laptop and go to your router's admin address — usually 192.168.1.1 or 192.168.0.1. Log in with your router admin username and password (not your Wi-Fi password). See the router security guide if you need help finding or using these credentials.

You should see your router's dashboard or settings page after logging in.
Step 2

Find the DNS Settings

DNS settings in router admin panels are typically found under one of these menus:

  • WAN or Internet settings — the most common location
  • Network > WAN
  • Advanced > DNS or DHCP
  • Some routers label it as DNS Server directly in the main menu

Look for fields labelled "Primary DNS", "DNS Server 1", "Preferred DNS", or similar. There will usually be two fields — one for the primary DNS server and one for the secondary (backup).

You may see the current values as your ISP's DNS addresses (often numbers starting with 203 or 124 for PNG ISPs). Write down the current values before changing them.
Step 3

Enter a Family-Safe DNS Address

Choose one of the following family-safe DNS services. Both are free, publicly available, and effective:

Service Primary DNS Secondary DNS Blocks
Cloudflare Family 1.1.1.3 1.0.0.3 Adult content + malware
OpenDNS FamilyShield 208.67.222.123 208.67.220.123 Adult content
Google (standard — limited filtering) 8.8.8.8 8.8.4.4 Minimal — not recommended for family filtering without extra setup

Recommended for most PNG homes: Use Cloudflare Family (1.1.1.3 / 1.0.0.3). It is fast, free, and blocks both adult content and malware sites. OpenDNS FamilyShield is also a solid choice and has been widely used for family filtering for many years.

Enter the Primary DNS value into the first DNS field, and the Secondary DNS value into the second field.

Both fields should contain the DNS addresses you chose. Double-check there are no extra spaces or typos — DNS addresses must be entered exactly.
Step 4

Save Settings and Restart Your Router

Click Save, Apply, or OK to save your DNS settings. Most routers will apply the new DNS settings without requiring a full restart, but restarting the router ensures all connected devices pick up the change cleanly.

  1. Save the settings in the router admin panel.
  2. Restart the router by turning it off, waiting 10 seconds, and turning it back on — or use the router's own restart option if available.
  3. Wait for the router to reconnect (usually 30–60 seconds).
  4. Reconnect your devices to Wi-Fi if needed.
Your internet connection should work as normal after restart. All devices on the Wi-Fi network will now use the family-safe DNS.
Step 5

Test That Filtering Is Working

After restarting, test that the filter is active and that normal browsing still works:

  1. Open a browser on a device connected to your home Wi-Fi.
  2. Try to visit a site that should be blocked — Cloudflare maintains a test page at https://1.1.1.3/help which shows your current DNS settings. You can also try searching for a known adult content site and see if it fails to load.
  3. Confirm that a normal site like google.com or youtube.com loads correctly. If normal sites are blocked, your DNS settings may be too restrictive — see the troubleshooting section.
Normal websites should load as expected. Blocked sites should fail to load or show a block page.

5 Method 2 — Browser-Level Controls

Browser controls work independently of your DNS settings and add filtering specifically for Google Search and YouTube. These are worth setting up even if you have already configured router DNS filtering, because they provide an additional layer for the most commonly used services.

Step A

Enable Google SafeSearch

SafeSearch filters explicit content from Google Search results. It does not block all harmful content, but it significantly reduces the likelihood of unsafe images or content appearing in search results.

  1. Open a browser and go to google.com/preferences or click Settings at the bottom of any Google Search page.
  2. Find the SafeSearch option.
  3. Select Filter explicit results (or the equivalent "On" setting for SafeSearch).
  4. Click Save at the bottom of the page.

To lock SafeSearch so it cannot be changed without a Google account password, you need to be signed into a Google account with Family Link or account permissions set up. Without locking, a user can simply return to settings and turn it off.

After saving, test by searching for a term known to return explicit images — the results should be filtered. A small label may appear at the top of results confirming SafeSearch is active.
Step B

Enable YouTube Restricted Mode

YouTube Restricted Mode filters mature content from search results and recommendations. It is not perfect, but it significantly reduces exposure to inappropriate videos.

  1. Go to youtube.com on a browser.
  2. Click your profile icon (top right) or the three-line menu.
  3. Scroll down to Restricted Mode at the bottom of the menu.
  4. Toggle it to On (Activate Restricted Mode).

Note: Restricted Mode is set per browser and per account. If family members use different browser profiles or accounts, Restricted Mode will need to be enabled in each one separately. If you are signed into a Google account in the browser, the setting may persist across sessions. Without sign-in, it may be cleared when the browser closes.

A label at the top of the YouTube page will confirm Restricted Mode is on. Videos that do not meet YouTube's restricted content criteria will be hidden from results and recommendations.

6 Common Mistakes

Mistake Why It Matters Fix
Relying only on router DNS and forgetting mobile data Phones using mobile data completely bypass the router's DNS filtering — the filter does not apply to any data not going through your home Wi-Fi Set device-level parental controls or screen time restrictions on phones that have their own mobile data SIM
Not testing after setup DNS settings may not save correctly, or the router may cache the old DNS temporarily — without testing you will not know if filtering is active Always test after setting up by checking Cloudflare's 1.1.1.3/help page and verifying a blocked category site does not load
Using filtering without explaining it to children Children who discover filtering without explanation may attempt to circumvent it, and the protective conversation about online safety does not happen Have a simple, age-appropriate conversation about why filtering is in place — it works better as part of a larger approach to online safety
Entering the wrong DNS address A typo in a DNS address will cause internet browsing to fail for all devices on the network Double-check each DNS address digit by digit. If browsing breaks after DNS change, revert to the original DNS values immediately
Forgetting to set browser controls on all devices SafeSearch and Restricted Mode are set per browser and per account — a device not configured will bypass the browser-level controls Go through each device used by children and set SafeSearch and Restricted Mode individually

7 Troubleshooting

Problem Likely Cause What to Try
Normal websites are being blocked unexpectedly The DNS filter is being too aggressive, blocking legitimate sites alongside restricted content Try switching to Cloudflare Family (1.1.1.3) instead of OpenDNS — Cloudflare's family filter tends to be less aggressive for general browsing while still blocking adult content and malware
DNS settings are not saving in the router The router may require a restart to apply changes, or you may not have clicked Save before closing the page Go back into router admin, re-enter the DNS values, click Save, and then restart the router from the admin panel or by power cycling it
A child bypassed the filter by switching to mobile data Mobile data on a phone does not route through your home router, so the router DNS settings do not apply Use the phone's built-in parental controls or screen time settings to apply restrictions on mobile data use. On Android, consider using Google Family Link. On iOS, use Screen Time (Settings > Screen Time)
Filtering was working but stopped after ISP reset the router Some ISPs remotely provision or reset router settings, which may overwrite custom DNS entries Log back into the router admin, re-enter the DNS settings, and contact your ISP to ask whether remote resets affect custom DNS configurations
SafeSearch or Restricted Mode turns off after browser closes These settings are stored per session or per browser profile — if the user is not signed into a Google account, they may not persist Sign into a Google account in the browser for these settings to persist across sessions. Note: a user can still change these settings if they have access to the Google account
