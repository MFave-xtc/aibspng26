## 5. Category Page Template

Each category page should include:

1. Category title.
2. Who this category helps.
3. PNG reality note.
4. Featured guides.
5. All guides in that category.
6. Related checklists.
7. Request help CTA.

Example:

```markdown
# Home Internet Safety

Secure your router, passwords, accounts, and family devices using practical steps designed for PNG homes.

## Start Here
- How to Secure Your Home or Small Office Wi-Fi Router
- Strong Passwords and Password Managers
- How to Turn On Two-Factor Authentication
```
